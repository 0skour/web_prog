# Movie Review Hub

A website where users can **browse movies**, *rate them with stars*, and read short reviews.

## Planned features

- Movie listing page with posters and titles
- Star rating (1-5) with a text description of each score
- User reviews for each movie
- Search and filter by genre

## Tech stack

1. Node.js
2. Express.js
3. HTML/CSS

## Run the demo script

```bash
npm install
npm run script
```

> This prints a sample star-rating description, a preview of the site's rating logic.
